Repositorio dedicado para el conjunto de animaciones de material de estudio de matemáticas generales.
El proyecto consiste en el uso de la libreria Manim, desarrollada originalmente por 3B1B.
Se utiliza el lenguaje de programación Python.

En este proyecto se utilizó la herramienta Obsidian para gestionar y planificar el contenido.
Se recomienda instalar la aplicacion y abrir la carpeta Math Animations como vault.

También sería ideal que se tenga un pequeño conocimiento de LaTex, si se desea leer el material que se planificó.

Se recomienda usar uv para la gestion de ambientes virtuales con python.
